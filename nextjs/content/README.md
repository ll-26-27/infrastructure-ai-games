This kit is for you to build with, not just to play. It is a set of small collections: mechanics, games, novels and films, and the ideas of your course. Two maps put them side by side, a map of the course and a map of what games are made of. A game is one way to make something where the two meet.

Start anywhere. Every page here is a Markdown file in `nextjs/content/`, so you can change any of it, and add your own by copying one.
