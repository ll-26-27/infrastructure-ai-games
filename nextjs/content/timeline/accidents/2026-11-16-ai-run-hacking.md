Google wrote that it had "identified threat actors using LLM frameworks to fully automate vulnerability discovery and exploitation without a human in the loop for the first time." The framework compared software before and after a security fix, drafted an exploit, ran it automatically and took data. Langdon Winner's phrase for this worry is autonomous technology: technology that runs on without anyone steering it.
